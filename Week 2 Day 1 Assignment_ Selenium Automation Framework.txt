## 🔑 Core Component Implementation Highlights

### 1️⃣ ConfigLoader.java (External File Support)
```java
public class ConfigLoader {
    private final Properties properties;
    
    public ConfigLoader(String env) {
        properties = new Properties();
        loadFromProperties(env);
        // Optional: Override with YAML/JSON if present
    }
    
    private void loadFromProperties(String env) {
        String path = "config/environments/" + env + ".properties";
        try (InputStream is = getClass().getClassLoader().getResourceAsStream(path)) {
            properties.load(is);
        } catch (IOException e) {
            throw new RuntimeException("Failed to load config: " + path, e);
        }
    }
    
    public String getBaseUrl() { return properties.getProperty("app.url"); }
    public int getImplicitWait() { return Integer.parseInt(properties.getProperty("wait.implicit", "10")); }
    // ... other typed getters
}
```

### 2️⃣ Hybrid POM + Component Pattern Example
```java
// BaseComponent.java (Reusable Widget Base)
public abstract class BaseComponent {
    protected WebDriver driver;
    protected WebDriverWait wait;
    
    public BaseComponent(WebDriver driver) {
        this.driver = driver;
        this.wait = new WebDriverWait(driver, Duration.ofSeconds(10));
    }
    
    protected <T extends BaseComponent> T getComponent(Class<T> componentClass) {
        try {
            return componentClass.getConstructor(WebDriver.class).newInstance(driver);
        } catch (Exception e) {
            throw new RuntimeException(e);
        }
    }
}

// DatePickerComponent.java
public class DatePickerComponent extends BaseComponent {
    private By calendarIcon = By.cssSelector(".date-picker-trigger");
    
    public DatePickerComponent selectDate(LocalDate date) {
        driver.findElement(calendarIcon).click();
        // ... date selection logic
        return this; // Fluent interface
    }
}

// LoginPage.java (Page Object using Components)
public class LoginPage extends BasePage {
    private final HeaderComponent header;
    private final DatePickerComponent datePicker;
    
    public LoginPage(WebDriver driver) {
        super(driver);
        header = getComponent(HeaderComponent.class);
        datePicker = getComponent(DatePickerComponent.class);
    }
    
    public DashboardPage login(String user, String pass) {
        // ... login steps
        return new DashboardPage(driver);
    }
}
```

### 3️⃣ RetryAnalyzer.java (Flaky Test Handling)
```java
public class RetryAnalyzer implements IRetryAnalyzer {
    private int count = 0;
    private static final int MAX_RETRY = 2; // Configurable via properties
    
    @Override
    public boolean retry(ITestResult result) {
        if (count < MAX_RETRY && !result.isSuccess()) {
            count++;
            result.setStatus(ITestResult.STARTED); // Reset for retry
            return true;
        }
        return false;
    }
}
// Usage: @Test(retryAnalyzer = RetryAnalyzer.class)
```

```java
public class Listener implements ITestListener {
    @Override
    public void onTestFailure(ITestResult result) {
        WebDriver driver = DriverManager.getDriver(); // ThreadLocal
        if (driver != null) {
            byte[] screenshot = ((TakesScreenshot) driver).getScreenshotAs(OutputType.BYTES);
            Allure.addAttachment("Failure Screenshot", "image/png", screenshot, "png");
            // Optional: Save to disk / trigger video capture
        }
    }
}
```

## 🔄 CI/CD Integration Examples

### Jenkinsfile (Declarative Pipeline)
```groovy
pipeline {
    agent any
    environment {
        ENV = 'qa'
        BROWSER = 'chrome'
    }
    stages {
        stage('Checkout') { steps { git url: 'https://your-repo.git' } }
        stage('Install') { steps { sh 'mvn clean install -DskipTests' } }
        stage('Test') {
            parallel {
                stage('Chrome') {
                    steps {
                        sh "mvn test -DsuiteXmlFile=testng.xml -Denv=${ENV} -Dbrowser=chrome"
                    }
                }
                stage('Firefox') {
                    steps {
                        sh "mvn test -DsuiteXmlFile=testng.xml -Denv=${ENV} -Dbrowser=firefox"
                    }
                }
            }
        }
        stage('Report') {
            steps {
                allure([includeProperties: false, jdk: '', properties: [[key: 'allure.results.directory', value: 'target/allure-results']]])
            }
        }
    }
    post {
        always {
            archiveArtifacts artifacts: '**/allure-results/**', allowEmptyArchive: true
        }
    }
}
```

## 💡 Pro Tips for Enterprise Success

- Tag tests with `@Groups` (smoke/regression/e2e) for selective execution
- Implement a `HealthCheckTest` that validates environment readiness before suite run

- Use `SoftAssert` for non-critical validations, but fail fast on auth/critical flows
